# CDN VideoHub — модуль для DataLife Engine

> Источник: [partners.cdnvideohub.com/docs/dle-module](https://partners.cdnvideohub.com/docs/dle-module)  
> Архив: [cdnvideohub.com/downloads/distr/dle/cdnvideohub.zip](https://cdnvideohub.com/downloads/distr/dle/cdnvideohub.zip)  
> Для Track Anime (Next.js) **не используется** — снимок для полноты партнёрской доки.  
> Карта ЛК: [partners-portal.md](./partners-portal.md)

---

## Зачем это в наших доках

Подтверждает из официального ЛК:

- поиск контента по **Kinopoisk / IMDb / MyAnimeList / MyDramaList**;
- плеер на странице только с **ID партнёра** (`pub`);
- тег шаблона `{cdnvideohub-player}` (аналог «места под виджет», не iframe-хост на чужом домене).

## Возможности (кратко)

- Поиск и простановка метаданных по внешним ID (KP / IMDb / MAL / MDL).
- Обновление при заходе в новость (синхронно или AJAX), с TTL «время проверки» в часах.
- Пропуск категорий / озвучек; стоп обновлений при качестве ≥ порога.
- Посезонная работа сериалов; категории DLE из жанров/стран.
- Массовая простановка, граббинг вручную или по крону.
- Плеер только там, где в `fullstory.tpl` стоит `{cdnvideohub-player}`.

---

## Установка (официальные шаги)

1. Загрузить файлы из папки `Module` на сервер.
2. Установить плагин `CDN Video Hub.xml` через систему плагинов DLE.
3. Права `777` на `/engine/cdnvideohub/data/` и `/engine/cdnvideohub/log/`.
4. Настроить модуль в админке.

Обновление с **1.3.0+**: в админке «Проверить версию» → «Обновить». Для версий ниже 1.3.0 — отдельная вкладка в доке ЛК.

---

## Настройки (вкладки в доке)

В ЛК вкладки: **Настройки**, **Плеер**, **Данные**, **Автообновление**, **Заполнение**, **Категории**, **Фильмы**, **Сериалы**.

Обязательные доп. поля DLE для матчинга: **ID Kinopoisk**, **ID IMDB**, **ID My Anime List**, **ID My Drama List** (достаточно тех, что есть у проекта).

### Вкладка «Плеер» (важно)

- Модуль **сам не вставляет** плеер в разметку — только тег `{cdnvideohub-player}` в шаблоне полной новости.
- **ID партнера** обязателен; без него плеер не выводится.
- Опции вроде «скрывать превью серии», «только выбор озвучки» соответствуют атрибутам виджета (`is-show-banner` / `is-show-voice-only` и т.п. в [player-setup-partners.md](./player-setup-partners.md)).

### Граббинг и крон

```
https://site.com/engine/ajax/controller.php?mod=grab_cron_cdnvideohub&key=Секретный_Ключ
```

Другая страница: `&page=2`.

Лицензионный крон:

```
https://site.com/engine/cdnvideohub/license_cron.php?key=Секретный_Ключ
```

Секретный ключ задаётся в админке модуля — **не коммитить**.

## FAQ (из ЛК)

| Вопрос | Ответ в доке |
|--------|----------------|
| Можно ли искать по названию? | **Данной возможности нет.** (только по внешним ID) |
| Не сохраняются настройки / «Сетевая ошибка» при поиске | Разборы в аккордеоне FAQ на странице ЛК; иначе — поддержка |

Это согласуется с Content API: поиск в API есть (`/titles/search`), но **DLE-модуль** по названию не ищет.
