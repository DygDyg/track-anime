# Справочники

> Источник: Content API Swagger → тег «Справочники»

Все запросы требуют `Authorization: Bearer <token>`.

Базовый префикс: `https://public-api.cdnvideohub.com`.

Перечни **стран** и **жанров** отдаются целиком, **без пагинации**, отсортированы по `code`.

---

## `GET /api/v1/countries` — страны

Все страны каталога: код (ISO 3166-1 alpha-2) и название.

### Ответ `200` — `ReferenceList`

```json
{
  "items": [
    { "code": "JP", "name": "Япония" }
  ]
}
```

### `ReferenceItem`

| Поле | Тип | Описание |
|------|-----|----------|
| `code` | string | Код |
| `name` | string | Название |

Ошибки: `401`, `500`.

---

## `GET /api/v1/genres` — жанры

Все жанры каталога: код и название. Без пагинации, сортировка по коду.

> Жанры с **одинаковым названием** остаются **разными** записями с разными `code`.

### Ответ `200` — `ReferenceList`

Тот же shape, что у стран: `{ "items": [ { "code", "name" } ] }`.

Ошибки: `401`, `500`.

Связь с тайтлами:

- в фильтрах `/titles?genres=` — коды через запятую;
- в карточке: `genres` (имена) + `genre_codes` (коды 1:1, без схлопывания).

---

## `GET /api/v1/studios` — студии

Список студий каталога.

### Ответ `200` — `StudioList`

```json
{
  "items": [
    {
      "code": "studio_code",
      "name": "Studio Name",
      "legacy_id": 123
    }
  ]
}
```

### `StudioItem`

| Поле | Тип | Описание |
|------|-----|----------|
| `code` | string | Код студии |
| `name` | string | Название |
| `legacy_id` | integer | Legacy-идентификатор |

Ошибки: `401`, `500`.

`studio_code` из `available_voices` / списков озвучек соотносится с `code` здесь.

---

## Дополнительно: фильтры тайтлов

Для UI-подсказок есть агрегат:

```http
GET /api/v1/titles/filters
```

Он возвращает **названия** стран/жанров (не коды), теги и диапазон годов. Для query-фильтров `/titles` всё равно нужны **коды** из `/countries` и `/genres`.

Подробнее → [titles.md](./titles.md#get-apiv1titlesfilters--доступные-фильтры).
