# AI Project Rules

Всегда:

* сначала изучай существующую реализацию
* переиспользуй existing patterns
* не предлагай новые архитектурные подходы без причины
* следуй conventions проекта

Перед изменением кода:

1. Найди похожую реализацию
2. Изучи dependencies
3. Проверь side effects

Никогда:

* не ломай backward compatibility
* не дублируй existing logic
* не создавай новые abstractions без необходимости
